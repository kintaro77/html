샴기르 서버 페트성장 확률 계산기

업데이트 : 2026/5/28

안녕하세요 !

이 페이지는 '샴기르' 서버 페트의 랭크 계산기입니다.
페트의 [ 모든 스탯이 A+이상 ] 으로 성장할 확률을 계산해 줍니다.
(1환의 경우 S이상, 2환의 경우 S+ 이상)

홈페이지 정보를 통해 추정하는 것이기에 오차가 발생할 수 있으므로
반드시 단순 참고용이나 재미로만 봐주시기를 부탁드리겠습니다 !!

검색되지 않는 페트의 경우 이름을 정확히 입력후 노환페트의 초기치와 성장율을 게임내 엘범에서 검색해 입력시 2환페트까지 성장확률을 계산하도록 해 두었습니다.
새페트의 경우 계수를 찾아내지 못해 계산이 불가할수 있습니다.

⚠️ 디비에 없는 페트를 최초로 계산했을경우 디비에 자동저장되므로 페트이름은 정확하게 입력 부탁드립니다.

사용된 페트의 데이터는 아래 링크를 통해 확인 하실 수 있습니다.
페트 데이터 확인하기 (구글 스프레드시트)

계산기 관련 문의는 구름비로 DM이나 정보란 계산기쪽에 문의 바랍니다.

    1-A. 노환 베이스 S급 1렙 초기치
    1-B. 노환 베이스 S급 성장률
    1환 S급 1렙 초기치
    1환 S급 성장률
    2-A. 내 펫의 1렙 표기 스탯 입력
    2-B. 환생 내부 보정치
